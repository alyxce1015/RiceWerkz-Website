## 🧩 Features

### Core Pages
- **Home** — hero image carousel, member cards, scrolling gallery, about, and contact  
- **Member Cars** — grid view of all member vehicles  
- **Vehicle Info** — individual car pages with specs and image galleries  
- **Gallery** — full photo gallery (in progress)  
- **Parts** — parts list page (in progress)  

---

## 📸 Media System (Cloudinary)

- Images are stored and delivered via Cloudinary  
- Media is organized using tags (e.g., Hero, Gallery)  
- Carousels and galleries dynamically fetch images by tag  
- No code changes required to add or remove images  

### Upload and Car Attribute Flow
- Members with secret key access in PWA have an editing hub which can:
  - Select image category (Hero / Gallery)
  - Upload photos directly from their device
  - Edit attributes of the vehicle they own such as performance, engine, and cosmetics.
  - contains admin id which can edit all categories and vehicles  
- Images appear on the site immediately after upload 
- Attributes updated after 2 min of saved changes 

---

## 🔄 Real-Time Updates

- Newly uploaded images are reflected instantly  
- Gallery and hero sections update dynamically and auto deployed using vercel
- Enables a live content pipeline for meets, events, and media drops  

---

## 🗄️ Backend & Admin System (Supabase)

- Backend powered by Supabase  
- Supports up to 6 authorized users for content editing  
- Used for:
  - Managing vehicle data  
  - Editing site content dynamically
  - Supporting future scalability (authentication, database expansion)  
  - Member only editing using unique secret key ids
